# Roadmap

## 0.1: a small engine you can inspect

Persistent campaigns, historical branches, knowledge snapshots, local cited retrieval, server dice, seeded events, immutable receipts, operating skill and real MCP transports. Single owner; no web UI.

## Candidates, not promises

- More original genres and CJK retrieval benchmarks.
- Alternative dice adapters with explicit validation contracts.
- Optional embeddings that preserve provenance and work without replacing lexical retrieval.
- A reviewable migration/backup/import format.
- A distinct multi-user/OAuth hosting adapter; never pretend a shared token provides tenant isolation.
- Human and model playtest fixtures for characterization, uncertainty and long-context continuity.

Please bring an actual use case and a small test before adding another abstraction. Server-side correctness and model-side storytelling need different evidence.
