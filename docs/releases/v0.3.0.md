# ChatQuest AI 0.3.0

Branchwright MCP is now ChatQuest AI. The repository and package are named `chatquest-ai`; the main command is `chatquest`.

```sh
npx --yes --package=https://github.com/KinsonLai/chatquest-ai/releases/download/v0.3.0/chatquest-ai-0.3.0.tgz chatquest
```

Append `--demo` to play the fresh ferry replay, `--http` to host MCP, or `--help` for options. Requires Node.js 24+. Distribution remains a GitHub release tarball, not an npm registry publication.

Existing games require no migration. Keep the same absolute `--db` path. The default `.branchwright/state.sqlite`, `branchwright` CLI alias, `BRANCHWRIGHT_*` environment variables, tool names, resource URIs and database format remain supported. New `CHATQUEST_*` variables take precedence when set. The original operating-skill text is retained to keep pending preparations valid. Historical release notes and playtest evidence are unedited.

The 22-test suite includes reopening a v0.2 fixture with its original receipt and pending failed roll, then committing that pending preparation with its original policy and context hashes. The complete ferry demo, IF preservation and real stdio/HTTP game tests remain in place. Package checks exercise both CLI names.

Refresh client metadata after upgrading to display the new server name. Account-level ChatGPT/Claude/Grok connections, an OAuth gateway and Docker execution remain unverified, as in the previous release.
