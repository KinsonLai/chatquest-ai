# Branchwright MCP 0.1.0 — preview

Your model tells the story. SQLite keeps the receipts.

First public preview of the MCP-only adventure engine:

- 17 tools with a bundled operating skill and live schemas.
- Persistent SQLite campaigns, exact-request receipts and historical IF branches.
- Character-specific knowledge snapshots and cited local canon search.
- Server-side d20 checks and deterministic time-driven world events.
- Original fantasy, space-salvage and urban-investigation packs.
- Official MCP SDK stdio and Streamable HTTP transports.
- English and Traditional Chinese onboarding, a runnable engine demo, CI and contribution templates.

Install the source with Node24+ and `npm ci`, then run `npm run demo` or connect a stdio client to `src/cli.mjs`. The attached `.tgz` is an npm-installable package, not a standalone executable and not an npm registry publication.

Verification: 14 local engine/transport tests, an independent in-memory model operating-skill exercise, package hygiene checks and a clean packaged-install smoke test. CI targets Linux, macOS and Windows. The Dockerfile is supplied, but the local Docker daemon was unavailable, so container runtime behavior is not claimed as verified.

This is a single-owner early release, not a multi-tenant OAuth service. Individual model-client UI integrations are unverified. Numerical validation does not guarantee characterization, semantic knowledge boundaries or model compliance. No web UI, proprietary story, private save or model API dependency is bundled.

Try an original world pack, file a reproducible bug, or contribute a genre. Stars help discovery; no engagement or model-quality guarantees are made.
