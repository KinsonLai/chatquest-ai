# Branchwright MCP 0.2.0 preview

Start the MCP server without cloning:

```sh
npx --yes --package=https://github.com/KinsonLai/branchwright-mcp/releases/download/v0.2.0/branchwright-mcp-0.2.0.tgz branchwright
```

Requires Node.js 24+ and npm. Stdio waits for a client; append `--demo` for a visible story replay, `--http` for the local HTTP endpoint, or `--help` for options. The package is distributed by GitHub Releases, not the npm registry. Pin the release URL and use an absolute `--db` path for persistent games.

This release adds:

- A fresh harbour story, The Last Ferry, with five main scenes, failure costs, a resolved evacuation and a played historical IF.
- A packaged `--demo` that exercises real MCP calls against a separate in-memory server. Its prose is scripted; dice are rolled by the server.
- English and Traditional Chinese connection guides for Claude Desktop/Code, remote Claude, ChatGPT and Grok, including transport and authentication differences.
- A separate model-led session: 31 MCP calls, five committed main scenes and two IF scenes, with actual requests, prose and receipts. The report preserves a prose-review finding rather than claiming perfect compliance.
- 20 tests covering full success/failure stories, authenticated HTTP gameplay, stdio, CLI, persistence and engine invariants.
- Revised English and Traditional Chinese READMEs.

No private story or formal save is included. ChatGPT's Secure MCP Tunnel requires its own permissions and runtime credential; public authenticated ChatGPT hosting needs an external MCP-compatible OAuth gateway. Account-level chat-product connections and Docker runtime remain unverified.
